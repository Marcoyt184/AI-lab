MNIST Handwritten Digit Classification
A simple TensorFlow/Keras neural network that classifies MNIST handwritten digits (0–9).

Files
MNIST_Digit_Classification.ipynb — complete notebook with data exploration, training, evaluation, plots, five predictions, and a neuron-count experiment.
MNIST_Assignment_Report_Guide.docx — report text to use as a guide when preparing the required handwritten report.
Requirements
pip install tensorflow numpy matplotlib jupyter
 
Run
Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab.
Run all cells from top to bottom.
Note the actual baseline and experiment test accuracies.
Include screenshots/plots and actual results in your submission.
The notebook downloads MNIST through tf.keras.datasets.mnist.load_data() when first run.
